# Privacy & Account

> **Last Updated:** 2026-08-07

Authenticated account controls:

- `GET/PUT /api/v1/users/me/privacy` — persisted communication, visibility, processing, and analytics preferences.
- `GET /api/v1/users/me/data-export` — JSON export of the user's profile and retained order summary.
- `DELETE /api/v1/users/me` — deletes the account and anonymizes retained orders.
